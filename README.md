# Biblioteca Acadêmica

Aplicação web didática para gerenciar uma biblioteca pessoal de livros. O sistema demonstra operações CRUD — criar, consultar, atualizar e excluir — em uma interface responsiva, com cadastro, login, redefinição de senha, pesquisa e tema claro/escuro.

## Como acessar

- **Acesso online:** Disponível na descrição do repositório
- **Localmente:** abra o arquivo `index.html` na raiz do projeto em um navegador moderno. É necessário estar conectado à internet para carregar as bibliotecas externas e acessar a API.

## Persistência

Para a persistência escolhi a API do Mimicry com o objetivo de ser algo mais didático e simples, já que o Mimicry entrega pronta a capacidade de criar um projeto CRUD simples. Este projeto foi feito de forma didática para simular uma necessidade real: um CRUD com interface web.

## Funcionalidades

- Criar conta, entrar e redefinir senha.
- Listar e pesquisar livros por título, autor, gênero ou ano.
- Adicionar livros com capa, consultar detalhes, atualizar e excluir.
- Navegar pelas páginas de resultados.
- Alternar entre tema claro e escuro.

Para conhecer a estrutura, os fluxos JavaScript, a responsividade e os estilos em detalhe, consulte o [Manual do projeto](./MANUAL_DO_PROJETO.md).
